```
var justString string

func someFunc() {
  v := createHugeString(1 &lt;&lt; 10)
  justString = v[:100]
}

func main() {
  someFunc()
}
```
### В коде выше присутсивует утечка памяти

1. Функция `createHugeString` создаёт строку большую строку
2. При присваивании `justString = v[:100]` создаётся не новая строка, а срез, ссылающийся на базовый массив строки `v`
3. Так как `justString` — глобальная переменная, она остаётся в памяти до конца работы программы
4. Исходная строка `v` не может быть удалена сборщиком мусора, поскольку её часть продолжает использоваться через `justString`
5. В памяти хранится больше тайтов, чем необзодимые 100.

**Решение с сохнанением глобальной переменной:** 

```go
func someFunc() {
    v := createHugeString(1 &lt;&lt; 10)
    justString = string([]byte(v[:100]))
}
```

Теперь исходная строка `v` освобождается после выхода из функции, а в памяти остаётся только 100 байт нужных данных.

**Решение с избавлением от глобальной переменной:**

```go
func someFunc() string {
    v := createHugeString(1 &lt;&lt; 10)
    return string([]byte(v[:100])) 
}
```
